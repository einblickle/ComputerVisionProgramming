Einlesen und Ausgabe der Datentypen und der Bildgröße¶

Dieses FarbGraustufen - Bild wird als numpy ndarray, einer v x u Zahlen - Matrix geladen. Der Datentyp der einzelnen Zahlen ist uint8

Die Koordinaten u, v repraesentieren hier die Pixelposition im Bild. Der Datentyp der einzelnen Zahlen ist uint8, d.h hier können 2^8 = 256 verschiedene Helligkeitswerte dargestellt werden

Machen Sie sich mit der Plotly Bildanzeige vertraut. Bewegen Sie den Mauszeige über das Bild, dann können Sie sowohl die Werte der Farbkanäle als auch die dazugehörigen Pixelkoordinaten auslesen.

In [2]:
imageLighthouse = cv2.imread(r'images/lighthouse.bmp', cv2.IMREAD_GRAYSCALE)
# Zur kontrolle Datentyp des Bildes Ausgeben
#Datentyp:
imageDataType = imageLighthouse.dtype
#Bildgröße
imageShape = imageLighthouse.shape

# Ausgabe der Daten
print(f'Datentyp des Bildes: {imageDataType}')
print(f'Größe des Bildes: {imageShape}')

# Anzeige des Bildes
fig = px.imshow(imageLighthouse, color_continuous_scale='gray')
fig.update_layout(
    margin=dict(l=0, r=0, t=0, b=0),
    width=500,
    height=500
)
fig.show()

Datentyp des Bildes: uint8
Größe des Bildes: (512, 512)

Hellster Pixel / Dunkelster Pixel¶

Den hellsten / dunkelsten Pixel kann man mit den Befehlen np.max / np.min und np.where finden.

Hellster Pixel¶

In [5]:
# Hellster Pixel:

# Maximalwert der Helligkeit
intensityMax = np.max(imageLighthouse)

# Jetzt kann die Position der hellsten Pixelel bestimmt werden.
# Mehrere Pixel besitzen den hellsen Helligkeitswert daher wird eine Liste zurückgegeben
(posOfMaxPixel_Y, posOfMaxPixel_X) = np.where(imageLighthouse==intensityMax)

# die Funktion np.where gibt eine Liste von Pixeln wieder.

print('Hellster Pixel:')
print(f'Grauwert: {intensityMax}')
print(f'Positionen der Hellsten Pixel x:{posOfMaxPixel_X}')
print(f'Positionem der Hellsten Pixel y:{posOfMaxPixel_Y}')

# Zur Überprüfung kann nun ein hellster Pixelwert ausgelesen werden

intensityCheck = imageLighthouse[posOfMaxPixel_Y[0], posOfMaxPixel_X[0]]
print(f'intensity Check:{intensityCheck}')
